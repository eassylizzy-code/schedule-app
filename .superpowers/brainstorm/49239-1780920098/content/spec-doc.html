Schedule App — Design Spec

2026-06-08

Overview

Персональное PWA-расписание для Лизы — недельный шаблон + месячный календарь, автоматическая синхронизация с iCloud Calendar. Mobile-first, устанавливается на iPhone, работает и на ноуте.

Контекст пользователя

Повторяющееся расписание:

  • Пн / Ср: занятия с детьми 10:00–12:30 и 17:00–19:30
  • Чт: занятие с ребёнком 10:00–12:30, взрослая клиентка 14:00–15:30 (1,5 ч)
  • Пт: занятие с ребёнком 17:00–19:30
  • Вт + Пт + Вс: зал (~1,5 ч, днём)
  • Каждый день (все 7): прогулки с собакой утром (~8:30) и вечером (~20:00), по 30 мин
  • Вт: блог + готовка
  • Чт вечером: готовка (после клиентки)
  • Вс: готовка + зал
  • Сб: уборка + учёба
  • Будни между сессиями: учёба (детская и взрослая психология)
  • Сб вечером / Вс: рисование, личное время
  • Один вечер в неделю (гибко): встреча с друзьями

Подъём в рабочие дни: не позже 8:20. Отбой: ~00:00–01:00.

Архитектура

Синхронизация

  1. Пользователь один раз вводит app-specific password от Apple ID в Настройках (хранится в localStorage — не уходит ни на какой сервер, кроме iCloud через API route)
  2. При открытии и каждые 5 минут: API route /api/caldav забирает события из iCloud
  3. При создании/редактировании/удалении: изменение сразу уходит в iCloud
  4. Изменения появляются в Apple Calendar на iPhone и Mac автоматически
  5. Напоминания хранятся как iCloud alarms — уведомления приходят от Apple Calendar нативно

Офлайн

  • Последние загруженные события кэшируются в localStorage
  • Без интернета расписание видно, синхронизация возобновляется при подключении
  • ⚠️ иконка в шапке когда данные могут быть устаревшими

Экраны

1. Недельный вид (главный)

  • Сетка 7 дней с временной осью (8:00–22:00)
  • Цветные блоки событий с иконкой, названием и длительностью
  • Тап на пустой слот → EventEditor (новое событие)
  • Тап на блок → EventEditor (редактировать/удалить)
  • Стрелки ← → для навигации по неделям
  • Автоскролл к текущему времени при открытии

2. Месячный вид

  • Стандартная сетка месяца с цветными точками на занятых днях
  • Тап на день → список событий дня
  • Тап на пустой день → EventEditor с предзаполненной датой

3. Редактор события (модалка)

  • Название, категория, дата + время начала/конца
  • Повтор: нет / каждую неделю / каждый день
  • Напоминание: нет / за 15 мин / 30 мин / 1 час
  • Кнопка удаления (красная, с подтверждением)

4. Настройки

  • Ввод app-specific password (скрытый)
  • Выбор календаря iCloud
  • Статус синхронизации + время последней синхронизации
  • Кнопка ручной синхронизации

Обработка ошибок

СитуацияПоведение
iCloud недоступенПоказываем кэш, ⚠️ в шапке
Неверный парольРедирект в Настройки с понятным сообщением
Конфликт правок с двух устройствПобеждает последнее изменение
Нет интернета при открытииЗагружаем localStorage, синхронизируем когда появится связь

Вне скоупа

  • Android (PWA работает, но не тестируется)
  • Google Calendar / другие CalDAV провайдеры
  • Совместные / общие календари
  • Drag-and-drop перетаскивание событий
